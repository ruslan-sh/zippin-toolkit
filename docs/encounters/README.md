# Encounter Difficulty Calculator

This framework-free D&D 5.5 tool calculates mixed-party XP thresholds and
ranks multiple independent encounters. See [calculator behavior](calculator.md)
for supported workflows, ranking rules, and boundaries.

## Development

Run the tool with the repository-level `npm run start`. Its TypeScript, SCSS,
template, and tests are in `src/apps/encounters/`. Production output is generated
under `dist/apps/encounters/`.
